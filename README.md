Rohingya Vocabulary
Learn • Practice • Grow

An educational vocabulary app designed
for Rohingya speakers learning English.

#Features

- English vocabulary with pictures
- Rohingya Hanifi translations
- Rohingyalish translations
- Burmese translations
- English pronunciation and examples
- Quizzes and learning progress
- Offline learning
- AI translation

Project Owner
Noor Islam

#Goal

Making English learning accessible
to Rohingya learners everywhere.
